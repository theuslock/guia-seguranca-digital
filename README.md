# 🛡️ Guia de Segurança Digital

> Meu primeiro projeto sobre segurança da informação — um guia acessível para todos aprenderem a se proteger na internet.

🔗 **Acesse aqui:** [theuslock.github.io/guia-seguranca-digital](https://theuslock.github.io/guia-seguranca-digital)

## 📌 Sobre o Projeto

Este guia foi criado com o objetivo de tornar conceitos de segurança digital simples e aplicáveis. Ideal para iniciantes que querem proteger suas contas, dados e privacidade online.

## 📚 Conteúdo

- ✅ **Autenticação em Dois Fatores (2FA)** — o que é, por que usar e como configurar
- 🔒 Senhas fortes e gerenciadores de senhas
- 🎣 Como identificar e evitar phishing
- 📱 Proteção de redes sociais e e-mail
- ⚙️ Passo a passo de configuração em serviços principais

## 🛠️ Tecnologias

- HTML5 + CSS3
- Markdown
- GitHub Pages (hospedagem)

## 🎯 Objetivos de Aprendizado

- Compreender os pilares da segurança da informação
- Explicar e demonstrar configuração de 2FA
- Criar conteúdo educativo acessível
- Publicar e manter projeto open-source
